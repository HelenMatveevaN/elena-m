*Масштабируемый REST API сервис для финансового учета и аналитики пользовательских подписок.*

Написала алгоритмическую логику для калькуляции пересечения периодов активности подписок в кастомных временных окнах. Оптимизировала выборки в PostgreSQL с помощью индексов, настроила автомиграции через `golang-migrate` и задокументировала API через Swagger.
